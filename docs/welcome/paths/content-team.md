# Content team path

This path is for writers, editors and SEO specialists who optimize existing pages and plan new ones with Agent WordLift. It lists the pages to read in order and links out to each one, so you can run your first content optimization quickly.

## Discover

Start at Agent WordLift, the entry point for content teams.

- **[Agent WordLift](/platform/agent-wordlift/).** See how Agent WordLift uses your Knowledge Graph and search data to research, analyze, create and optimize content.

## Onboard

Take a guided start, then try keyword research in a familiar spreadsheet.

- **[Get started with Agent WordLift](/platform/agent-wordlift/getting-started/).** Open [agent.wordlift.io](https://agent.wordlift.io), enter your WordLift key in the Settings panel and run your first prompts.
- **[SEO Add-on for Google Sheets](/tools/google-sheets-addon/).** Run semantic keyword research and entity analysis in Google Sheets. The add-on is included in Business+ and Enterprise.

## Configure

Connect the search data the workflows draw on and set up reusable prompts. Connect Google Search Console before you run workflows that use search data.

- **[Connect Google Search Console](/platform/data-sources/oauth2/).** Authorize Google Search Console from **Data Sources** in the Dashboard.
- **[Prompt Library](/platform/agent-wordlift/prompt-library/).** Copy ready-to-use prompts for common jobs.
- **[WordPress plugin](/integrations/wordpress-plugin/).** If your team already runs the classic WordPress plugin, use it to manage entities in WordPress. New sites start with [WordLift Cloud](/welcome/install-wordlift-cloud/).

## Activate

Run the core content optimization jobs.

- **[Evaluate content quality](/platform/agent-wordlift/workflows/content-evaluation/).** Score a page or text for quality, readability and SEO, and get suggestions to improve it.
- **[Align content with the intended search query](/platform/agent-wordlift/workflows/analyzing-query-match/).** Check a page against its target query and search intent.
- **[Create internal links](/platform/agent-wordlift/workflows/create-internal-links/).** Find related articles and generate the HTML for internal links.

## Expand

Move from optimizing existing pages to planning new content.

- **[Run keyword research](/platform/agent-wordlift/workflows/keyword-discovery/).** Analyze a query, check its seasonal trends and draft an outline.
- **[Rankings drop audit](/platform/agent-wordlift/workflows/rankings-drop-audit/).** Analyze ranking drops in your Google Search Console data to plan your recovery.
- **[Enhanced entity research with Google Knowledge Graph](/platform/agent-wordlift/workflows/enhanced-entity-research/).** Research people, companies, places and concepts for new content.
