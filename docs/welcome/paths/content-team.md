# Content team path

This path is for writers, editors and SEO specialists who optimize existing pages and plan new ones with Agent WordLift. It lists the pages to read in order and links out to each one, so you can run your first content optimization quickly.

## Discover

Start at Agent WordLift, the entry point for content teams.

<Cards cols={2}>
  <Card title="Agent WordLift" href="/platform/agent-wordlift/">
    See how Agent WordLift uses your Knowledge Graph and search data to research, analyze, create and optimize content.
  </Card>
</Cards>

## Onboard

Take a guided start, then try keyword research in a familiar spreadsheet.

<Cards cols={2}>
  <Card title="Get started with Agent WordLift" href="/platform/agent-wordlift/getting-started/">
    Open [agent.wordlift.io](https://agent.wordlift.io), enter your WordLift key in the Settings panel and run your first prompts.
  </Card>
  <Card title="SEO Add-on for Google Sheets" href="/tools/google-sheets-addon/">
    Run semantic keyword research and entity analysis in Google Sheets. The add-on is included in Business+ and Enterprise.
  </Card>
</Cards>

## Configure

Connect the search data the workflows draw on and set up reusable prompts. Connect Google Search Console before you run workflows that use search data.

<Cards cols={2}>
  <Card title="Connect Google Search Console" href="/platform/data-sources/oauth2/">
    Authorize Google Search Console from **Data Sources** in the Dashboard.
  </Card>
  <Card title="Prompt Library" href="/platform/agent-wordlift/prompt-library/">
    Copy ready-to-use prompts for common jobs.
  </Card>
  <Card title="WordPress plugin" href="/integrations/wordpress-plugin/">
    If your team already runs the classic WordPress plugin, use it to manage entities in WordPress. New sites start with [WordLift Cloud](/welcome/install-wordlift-cloud/).
  </Card>
</Cards>
