# Glossary

One-sentence definitions of the terms used across these docs, in alphabetical order. Each entry links to the page that explains it in full, and each term has its own anchor, so you can link to it directly. Capitalized names such as Knowledge Graph and GraphSync are WordLift products; lowercase terms such as knowledge graph and linked data are general concepts.

## A to D

### Agent WordLift {#agent-wordlift}

The WordLift product that works on your Knowledge Graph and connected search data to research, analyze, create and optimize content; it is included in Business+ and Enterprise and is not a plan of its own. Read [Agent WordLift](/platform/agent-wordlift/).

### AI Mode {#ai-mode}

Google's conversational AI search experience, which Agent WordLift can query to see how it answers and which sources it cites. Read [AI visibility](/concepts/ai-visibility/).

### AI Overview {#ai-overview}

The AI-generated summary Google shows in search results, with a list of cited sources that Agent WordLift can inspect. Read [AI visibility](/concepts/ai-visibility/).

### AI visibility {#ai-visibility}

The degree to which your brand and content are found, cited and recommended in answers generated by AI systems. Read [AI visibility](/concepts/ai-visibility/).

### Business+ {#business-plus}

One of the two WordLift plans, for growing businesses scaling AI search and SEO; Enterprise includes everything in it. Read [Business+](/plans-and-pricing/business-plus/).

### Data API {#data-api}

The API that publishes the structured data for a web page from the Knowledge Graph as JSON-LD. Read [Data API](/apis-and-sdks/data-api/).

### Dataset URI {#dataset-uri}

The namespace under which every entity identifier in a graph sits, hosted by WordLift or, for Enterprise, on a customer-controlled domain. Read [Linked data](/concepts/linked-data/#uris-dereferencing-and-your-dataset-uri).

### Dereferencing {#dereferencing}

Looking up a URI on the web to get information about the resource it identifies. Read [Linked data](/concepts/linked-data/#uris-dereferencing-and-your-dataset-uri).

## E to J

### Embedding {#embedding}

A list of numbers that represents the meaning of a piece of text, stored in the graph so vector search can find passages with similar meaning. Read [RAG and LLMs](/concepts/rag-and-llms/#embeddings-in-the-knowledge-graph).

### Enterprise {#enterprise}

The WordLift plan for organizations that need a custom scope; it includes everything in Business+ and adds SAML single sign-on and a custom domain. Read [Enterprise](/plans-and-pricing/enterprise/).

### Entity {#entity}

A real-world thing, such as a person, place, product or topic, described in a knowledge graph with a stable identifier, a type and properties. Read [Entities](/concepts/entities/).

### Feature Matrix {#feature-matrix}

The canonical table of which WordLift capabilities are in Business+ and Enterprise. Read [Feature Matrix](/plans-and-pricing/feature-matrix/).

### GEO and AEO {#geo-and-aeo}

Acronyms for practices that aim to make content visible in AI-generated answers; WordLift recommends server-side JSON-LD when they are a priority. Read [AI visibility](/concepts/ai-visibility/).

### GraphQL API {#graphql-api}

The API for live queries against the data in a Knowledge Graph, selecting properties by prefixed names such as `schema:name`. Read [GraphQL API](/apis-and-sdks/graphql-api/).

### GraphSync {#graphsync}

The recommended way for Business+ and Enterprise customers to create and maintain a content Knowledge Graph, using reusable mappings and stable entity identities. Read [GraphSync](/platform/knowledge-graph/graph-sync/).

### IRI {#iri}

An Internationalized Resource Identifier, a web identifier like a URI that can also contain non-ASCII characters; WordLift names each entity with one, as in the `@id` of its JSON-LD. Read [Entities](/concepts/entities/).

### JSON-LD {#json-ld}

JSON for Linked Data, the format WordLift uses to publish structured data in a page's `application/ld+json` script tag. Read [JSON-LD](/concepts/json-ld/).

## K to R

### KG-REST {#kg-rest}

The REST API for creating, reading, updating, deleting, batch processing and exporting the data in a Knowledge Graph. Read [KG-REST](/apis-and-sdks/kg-rest/).

### Knowledge graph and Knowledge Graph {#knowledge-graph}

Lowercase, a network of entities and the relationships between them; capitalized, the WordLift product that holds the entities that matter to your website or organization. Read [Knowledge graph](/concepts/knowledge-graph/).

### Linked data {#linked-data}

A way of publishing structured data in which things are named with URIs and linked to other things by those URIs. Read [Linked data](/concepts/linked-data/).

### Linked Open Data {#linked-open-data}

Linked data published as open content, such as DBpedia and Wikidata. Read [Linking to Linked Open Data](/concepts/linked-data/#linking-to-linked-open-data).

### MCP Server {#mcp-server}

The WordLift Model Context Protocol (MCP) Server, an access surface that lets AI assistants call Agent WordLift and query your Knowledge Graph; it is available on both plans and is not a plan. Read [MCP Server](/tools/mcp-server/).

### Product Knowledge Graph {#product-knowledge-graph}

The e-commerce part of a WordLift Knowledge Graph, built from a Google Merchant Center feed with the Product Knowledge Graph Builder. Read [Product Knowledge Graph](/platform/knowledge-graph/product-knowledge-graph/).

### RAG {#rag}

Retrieval-augmented generation, a pattern in which an application retrieves facts from a data source and passes them to a language model to ground its answer. Read [RAG and LLMs](/concepts/rag-and-llms/).

### RDF {#rdf}

Resource Description Framework, the W3C standard for representing information as triples, which WordLift uses for its graph exports. Read [Linked data](/concepts/linked-data/).

### Reconciliation {#reconciliation}

Linking an entity in your data to the same entity in another dataset, also called disambiguation, so machines can identify it without ambiguity. Read [Entities](/concepts/entities/#reconciliation-and-sameas).

### Resolve API {#resolve-api}

The self-serve WordLift API that resolves mentions in a text to stable identifiers in Wikidata, your Knowledge Graph or an inline vocabulary, or returns `unresolved`. Read [Resolve API guide](/apis-and-sdks/resolve/).

## S to Z

### sameAs {#sameas}

A property (`schema:sameAs` or `owl:sameAs`) that states two identifiers refer to the same thing. Read [Entities](/concepts/entities/#reconciliation-and-sameas).

### Schema.org {#schema-org}

The shared vocabulary of types and properties that WordLift uses to describe entities in structured data. Read [Schema.org](/concepts/schema-org/).

### Semantic fingerprint {#semantic-fingerprint}

A WordPress plugin term for the unique linked identifier that semantic annotation adds to a post's HTML to mark which entity a passage refers to. Read [Concepts](/concepts/#semantic-fingerprint).

### SHACL {#shacl}

Shapes Constraint Language, a W3C standard for validating RDF data, used by the Python SDK with shapes generated from Google Search Gallery requirements. Read [Schema.org validation](/concepts/schema-org/#validation).

### Triple {#triple}

A single fact made of a subject, a predicate and an object; triples link together to form a graph. Read [Knowledge graph](/concepts/knowledge-graph/).

### Turtle {#turtle}

A compact text format for RDF, one of the formats in which you can export a Knowledge Graph. Read [Linked data](/concepts/linked-data/).

### Vocabulary {#vocabulary}

Your curated collection of entities in WordLift, or a schema vocabulary such as schema.org that defines types and properties. Read [Vocabulary](/concepts/vocabulary/).

### worai CLI {#worai-cli}

The command-line tool for building, synchronizing and auditing a Knowledge Graph, distinct from wordlift-cli. Read [Install the worai CLI](/tools/worai-cli/install/).

### WordLift Cloud {#wordlift-cloud}

The hosted way to publish your Knowledge Graph's structured data on any website through one script, `bootstrap.js`. Read [Install WordLift Cloud](/platform/knowledge-graph/schema-publishing/wordlift-cloud/).

### WordLift key {#wordlift-key}

The credential that authenticates requests to WordLift APIs and connectors; each Knowledge Graph has its own key. Read [Authentication](/apis-and-sdks/#authentication).

### wordlift-cli {#wordlift-cli}

A terminal client for Agent WordLift that connects through the MCP Server, distinct from the worai CLI. Read [wordlift-cli](/tools/wordlift-cli/).
