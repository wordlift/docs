# Contact WordLift

Before you write, check the [FAQ](/support/faq/), [Troubleshooting](/support/troubleshooting/) and [Service status](/support/status/): many problems have a documented fix. When you need a person, use the channel for your request type below.

## Choose the right channel

| Request type | Channel | Notes |
| --- | --- | --- |
| Technical support | [support@wordlift.io](mailto:support@wordlift.io) | Errors, missing data, setup problems. See [what to include](#technical-support). |
| Missing Dashboard access | Your WordLift account team, or [support@wordlift.io](mailto:support@wordlift.io) | For existing customers who cannot sign in. |
| Start with Business+ | [Book a Business+ discovery session](https://wordlift.io/business-plus-get-started/) | Access is sales-led. |
| Start with Enterprise | [Send an Enterprise enquiry](https://wordlift.io/enterprise-enquiry/) | Enterprise is a custom quote. |
| Plan changes, credits and billing | Your account manager | For existing customers. See [Billing](/plans-and-pricing/billing/). |
| Resolve API access | [Get access](/apis-and-sdks/#get-access) | Self-serve; no sales conversation needed. |
| General questions | [WordLift contact form](https://wordlift.io/contact-us/) | Anything that does not fit another row. |
| Privacy and data deletion | [hello-gdpr@wordlift.io](mailto:hello-gdpr@wordlift.io) or the [GDPR request form](https://wordlift.gdprform.io/) | See [Privacy and data requests](#privacy-and-data-requests). |
| Classic WordPress plugin bugs | [wordlift-plugin issue tracker on GitHub](https://github.com/insideout10/wordlift-plugin/issues) | For existing installs. See [WordPress plugin issues](#wordpress-plugin-issues). |

## Technical support {#technical-support}

Email [support@wordlift.io](mailto:support@wordlift.io). To get a useful answer on the first reply, include:

- **Account.** Your account or Knowledge Graph (dataset) name. Do not send your API key.
- **Where.** The page URL or API endpoint involved.
- **Steps.** What you did, in order, and what you expected.
- **Error.** The exact error text or response, including any `code` value.
- **When.** The date and time it happened, with your time zone.

Response times and SLAs depend on your contract.

## Sales and plan changes {#sales-and-plan-changes}

Business+ and Enterprise access is sales-led; there is no free trial or self-serve signup for either plan.

- **New to Business+.** [Book a discovery session](https://wordlift.io/business-plus-get-started/).
- **New to Enterprise.** [Send an Enterprise enquiry](https://wordlift.io/enterprise-enquiry/) for a custom quote.
- **Existing customers.** Contact your account manager to change your plan, buy more credits or discuss renewal.
- **Developers who only need the Resolve API.** Get access self-serve, without a sales conversation. See [Get access](/apis-and-sdks/#get-access).

To compare the plans first, see [Plans and pricing](/plans-and-pricing/) and the [Feature Matrix](/plans-and-pricing/feature-matrix/).

## Privacy and data requests {#privacy-and-data-requests}

To ask WordLift to delete your account information, email [hello-gdpr@wordlift.io](mailto:hello-gdpr@wordlift.io) or submit the [GDPR request form](https://wordlift.gdprform.io/). Before you request deletion, [export your Knowledge Graph data](/support/faq/#how-can-i-download-my-knowledge-graph-data).

## WordPress plugin issues {#wordpress-plugin-issues}

The classic WordPress plugin is supported for existing installs. Report bugs in the [wordlift-plugin issue tracker on GitHub](https://github.com/insideout10/wordlift-plugin/issues), or ask a question with the [`wordlift` tag on Stack Overflow](https://stackoverflow.com/questions/tagged/wordlift). For account or setup problems, email [support@wordlift.io](mailto:support@wordlift.io).
