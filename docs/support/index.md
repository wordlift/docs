# Support

Most questions have an answer in the docs. Start with the FAQs and troubleshooting, check service status if something stopped working, and contact WordLift when you need a person.

## Find an answer

- **[Frequently asked questions](/support/faq/).** Answers on data ownership, export, security, plans and the classic WordPress plugin.
- **[Troubleshooting](/support/troubleshooting/).** Find your symptom and follow the link to the fix.
- **[Agent WordLift FAQ](/platform/agent-wordlift/faq/).** Answers on what Agent WordLift does, how usage is counted and how to work with its output.
- **[Knowledge Graph FAQ](/platform/knowledge-graph/#frequently-asked-questions).** Answers on JSON-LD delivery, data ownership and GraphSync.
- **[WordPress plugin support](/integrations/wordpress-plugin/support/).** Help for existing installs of the classic WordPress plugin.

## Check service status

If WordLift calls fail or the Dashboard misbehaves, check [Service status](/support/status/) first. It points to the live status page at [status.wordlift.io](https://status.wordlift.io).

## Contact WordLift

[Contact WordLift](/support/contact/) lists the right channel for each request: technical support at [support@wordlift.io](mailto:support@wordlift.io), sales and plan changes, and privacy requests.

## Stay up to date

[What's new](/whats-new/) is the product release feed. It lists new features, changes and deprecations.
