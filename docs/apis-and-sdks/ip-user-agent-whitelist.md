# IP and User-Agent whitelist

To allow WordLift to correctly analyze your website, whitelist the following IP addresses and user agent in your firewall, WAF, or bot-management rules.

## Whitelist IP addresses {#whitelist-ip-addresses}

- 52.177.137.80
- 20.22.128.152
- 20.75.17.9
- 52.252.16.185
- 188.8.4.228
- 34.52.203.209

## Whitelist User-Agent {#whitelist-user-agent}

- Any User-Agent value that contains `WLBot` (not an exact match).
