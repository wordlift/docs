# Agent WordLift

Agent WordLift is the agentic AI pillar of the WordLift platform. It works on your Knowledge Graph and connected data, such as Google Search Console and Google Analytics, to research, analyze, create and optimize content.

Agent WordLift is included in Business+ and Enterprise. To get access, [compare the plans](/plans-and-pricing/) and book a discovery session with the WordLift team.

## What you can do

- **Find out why rankings dropped.** The [rankings drop audit](/platform/agent-wordlift/workflows/rankings-drop-audit/) compares your Search Console data before and after a drop and groups the affected pages by topic, so you know where to act first.
- **Measure your AI visibility.** The [AI visibility analysis](/platform/agent-wordlift/workflows/ai-visibility-analysis/) measures the traffic AI assistants send you and checks whether you are cited in Google AI Overviews and AI Mode for your key queries.
- **Improve the pages you already have.** The [content evaluation workflow](/platform/agent-wordlift/workflows/content-evaluation/) scores a page for quality, readability and SEO, and the [query match workflow](/platform/agent-wordlift/workflows/analyzing-query-match/) checks it against the search intent you target.
- **Create content from your own data.** Workflows for [product descriptions](/platform/agent-wordlift/workflows/create-product-description/), [social posts](/platform/agent-wordlift/workflows/create-social-media-posts/) and [FAQs](/platform/agent-wordlift/workflows/generate-faqs/) start from your site content, keyword insights and entity gaps.
- **Strengthen your local presence.** The [local SEO analysis](/platform/agent-wordlift/workflows/local-seo-analysis/) reviews your Google Business Profile, Local Pack results and local rankings against nearby competitors.

## How it works

Agent WordLift has two layers:

- **The Knowledge Graph is its memory.** Your [Knowledge Graph](/platform/knowledge-graph/) stores entities, relationships, structured data, search signals and context about your site. Agent WordLift grounds its answers in this curated data.
- **Specialized tools do the work.** Agent WordLift retrieves evidence, analyzes, generates, validates and automates through specialized tools, grouped into [tool families](/platform/agent-wordlift/tool-families/) such as entity gap analysis, content quality evaluation and fact-checking.

A single request can combine several tools. Agent WordLift can also read your Google Search Console and Google Analytics data directly once you connect them as [data sources](/platform/data-sources/oauth2/) in the WordLift Dashboard.

## Access methods

Use Agent WordLift in the web app, or bring it into the tools you already work in.

| Access method | Use it when | Guide |
| --- | --- | --- |
| Web app | You want to chat with Agent WordLift in the browser at [agent.wordlift.io](https://agent.wordlift.io). | [Get started with Agent WordLift](/platform/agent-wordlift/getting-started/) |
| MCP Server | You want to use Agent WordLift and query your Knowledge Graph from an AI assistant that supports the Model Context Protocol (MCP). | [MCP Server](/tools/mcp-server/) |
| Agent WordLift Skill | You want an MCP-capable assistant to follow WordLift tool routing, SEO audits, a verified GraphQL reference, the Prompt Library and workflow recipes. | [Agent WordLift Skill](/tools/agent-wordlift-skill/) |
| wordlift-cli | You prefer working in the terminal or want to script Agent WordLift tasks. | [wordlift-cli](/tools/wordlift-cli/) |
| Agent WordLift API | You want to send messages to Agent WordLift from your own application through the `/ask` endpoint. | [Agent WordLift API reference](/apis-and-sdks/api-reference/agent/wordlift-agent-api/) |
| Zapier | You want to run Agent WordLift inside automated workflows with other apps. | [Zapier](/integrations/zapier/) |
| Chrome Extension | You want to run entity analysis on the page you are viewing and check your WordLift Cloud setup in Chrome. | [Agent WordLift Extension](/tools/chrome-extension/) |

For a summary of every integration surface, see [Agent WordLift integrations](/platform/agent-wordlift/integrations/).
